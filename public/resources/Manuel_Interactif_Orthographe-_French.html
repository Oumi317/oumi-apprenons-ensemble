🔤 Leçon 1 : Les sons et leur écriture

Les sons en français CP-CE

Un même son peut s'écrire de différentes façons. Il faut apprendre les différentes graphies.

Les principales écritures des sons

Le son [o]

  • o : robot, moto
  • au : chaud, auto
  • eau : bateau, chapeau
  • ô : drôle, côte

Le son [è]

  • è : mère, frère
  • ê : forêt, fête
  • e + consonne double : terre, belle
  • ai : maison, lait
  • ei : neige, reine
  • et (à la fin) : jouet, poulet

Le son [in]

  • in : lapin, jardin
  • im : timbre, simple
  • ain : pain, main
  • aim : faim
  • ein : frein, plein
  • un : brun, un

📐 Leçon 2 : Les accents

À quoi servent les accents ? CP-CE

Les accents permettent de modifier la prononciation des lettres et de distinguer certains mots.

Les différents accents

1. L'accent aigu (é)

Se place uniquement sur le e et se prononce [é]

Ex : école, été, éléphant, café

2. L'accent grave (è, à, ù)

Sur le e : se prononce [è]

Ex : mère, après, élève

Sur le a : permet de distinguer des mots

Ex : à (préposition) ≠ a (verbe avoir)

Sur le u : uniquement dans "où" (lieu/question)

Ex : où (lieu) ≠ ou (choix)

3. L'accent circonflexe (ê, â, î, ô, û)

Se place sur toutes les voyelles

Ex : tête, pâte, île, hôtel, flûte

Souvent, il remplace un s ancien : forêt (forest), hôpital (hospital)

4. Le tréma (ë, ï, ü)

Indique que la voyelle se prononce séparément

Ex : Noël (no-el), maïs (ma-is), aïe

🎵 Leçon 3 : m devant m, b, p

La règle du m CP-CE

Devant les lettres m, b, p, on écrit m au lieu de n

Application de la règle

Les sons avec m

  • [an] → am : jambe, chambre, lampe, campagne
  • [on] → om : ombre, tomber, pompe, pompier
  • [in] → im : timbre, simple, important, impossible
  • [un] → um : parfum, humble

⚠️ Exceptions à connaître

  • bonbon, bonbonne, bonbonnière (on garde le n)
  • néanmoins, embonpoint

Astuce pour retenir

Les lettres m, b, p sont prononcées avec les lèvres fermées, comme le m !

🎨 Leçon 4 : c, ç, g, gu

Les règles de position CE

La lettre c et la lettre g se prononcent différemment selon la voyelle qui suit.

La lettre c

1. Le c se prononce [k]

Devant a, o, u et devant une consonne

Ex : cartable, colle, cube, classe, cri

2. Le c se prononce [s]

Devant e, i, y

Ex : cerise, ciel, cygne

La cédille (ç) : pour faire [s] devant a, o, u

Ex : ça, garçon, déçu, leçon

La lettre g

1. Le g se prononce [g]

Devant a, o, u et devant une consonne

Ex : gare, gomme, légume, grand

Le u muet : pour faire [g] devant e, i

Ex : gui, guirlande, guerre, guépard

2. Le g se prononce [ʒ] (comme dans "je")

Devant e, i, y

Ex : girafe, genou, gymnase

Le e muet : pour faire [ʒ] devant a, o

Ex : mangeons, nageoire, pigeon

🤫 Leçon 5 : Les lettres muettes

Qu'est-ce qu'une lettre muette ? CE-CM

Une lettre muette est une lettre qui s'écrit mais ne se prononce pas.

Les lettres muettes finales

Les consonnes muettes

À la fin des mots, certaines consonnes ne se prononcent pas :

  • -d : grand, froid, nid, pied
  • -s : souris, bras, temps, corps
  • -t : chat, lit, dent, sport
  • -p : loup, drap, camp, beaucoup
  • -x : voix, croix, paix, choix
  • -z : nez, riz, chez

Astuce pour trouver la lettre muette

Cherche un mot de la même famille où on entend la lettre :

  • grand → grandir
  • chat → chaton
  • dent → dentiste
  • bras → brassard

Le h muet

Le h ne se prononce jamais en français :

  • h muet : permet l'élision → l'homme, l'heure
  • h aspiré : empêche l'élision → le héros, la hache

👯 Leçon 6 : Les consonnes doubles

Le doublement des consonnes CE-CM

Certaines consonnes peuvent être doublées à l'intérieur des mots.

Quelles consonnes peut-on doubler ?

Les consonnes qui se doublent souvent

  • ll : belle, balle, ville
  • mm : pomme, comme, femme
  • nn : année, canne, personne
  • pp : appeler, nappe, grippe
  • rr : terre, verre, courrir
  • ss : poisson, tasse, dessin
  • tt : lettre, nettayer, mettre
  • ff : affaire, offrir, difficile

⚠️ Attention au s entre deux voyelles

s entre deux voyelles se prononce [z] :

  • maison, poison, rasoir → [z]

Pour faire le son [s], il faut doubler le s :

  • poisson, dessin, tasse → [s]

Les mots en -tion

Les mots se terminant par -tion ne doublent jamais le t :

Ex : addition, émotion, station, attention

📚 Leçon 7 : Le pluriel des noms

Former le pluriel CP-CE-CM

Le pluriel indique qu'il y a plusieurs personnes, animaux ou choses.

Les règles du pluriel

1. Règle générale : + s

On ajoute un -s au singulier

Ex : un chat → des chats, une table → des tables

2. Mots en -s, -x, -z : pas de changement

Ex : une souris → des souris, une voix → des voix, un nez → des nez

3. Mots en -eau, -au, -eu : + x

Ex : un bateau → des bateaux, un noyau → des noyaux, un cheveu → des cheveux

⚠️ Exceptions : des pneus, des bleus, des landaus

4. Mots en -al : → -aux

Ex : un cheval → des chevaux, un animal → des animaux

⚠️ Exceptions : des bals, des festivals, des carnavals

5. Mots en -ou : + s (avec 7 exceptions en -x)

Règle générale : un trou → des trous

7 exceptions qui prennent -x :

bijou, caillou, chou, genou, hibou, joujou, pou

Ex : un bijou → des bijoux

♀️ Leçon 8 : Le féminin des noms et adjectifs

Former le féminin CP-CE-CM

Le féminin marque le genre féminin d'un nom ou d'un adjectif.

Les règles du féminin

1. Règle générale : + e

On ajoute un -e au masculin

Ex : un ami → une amie, petit → petite

2. Doublement de la consonne + e

  • -el → -elle : réel → réelle
  • -en → -enne : ancien → ancienne
  • -on → -onne : bon → bonne
  • -et → -ette : muet → muette

3. Changements particuliers

  • -er → -ère : boulanger → boulangère
  • -eur → -euse : chanteur → chanteuse
  • -teur → -trice : acteur → actrice
  • -eux → -euse : heureux → heureuse
  • -f → -ve : neuf → neuve, vif → vive

4. Féminins irréguliers

  • blanc → blanche
  • frais → fraîche
  • doux → douce
  • long → longue
  • faux → fausse

🔀 Leçon 9 : Homophones a/à et et/est

Les homophones CE-CM

Des mots qui se prononcent pareil mais s'écrivent différemment.

a / à

a sans accent

C'est le verbe avoir au présent (il/elle/on a)

Astuce : On peut le remplacer par avait

Ex : Il a un chat. → Il avait un chat.

à avec accent

C'est une préposition

Astuce : On ne peut PAS le remplacer par avait

Ex : Je vais à l'école. → Je vais avait l'école. ✗

et / est

et

C'est une conjonction de coordination (relie des mots)

Astuce : On peut le remplacer par et puis

Ex : Pierre et Marie. → Pierre et puis Marie.

est

C'est le verbe être au présent (il/elle/on est)

Astuce : On peut le remplacer par était

Ex : Il est content. → Il était content.

🔄 Leçon 10 : Homophones son/sont et on/ont

Distinguer son/sont et on/ont CE-CM

son / sont

son

C'est un déterminant possessif (à lui)

Astuce : On peut le remplacer par mon ou ton

Ex : Il range son livre. → Il range mon livre.

sont

C'est le verbe être au présent (ils/elles sont)

Astuce : On peut le remplacer par étaient

Ex : Ils sont contents. → Ils étaient contents.

on / ont

on

C'est un pronom personnel (= nous, quelqu'un)

Astuce : On peut souvent le remplacer par il ou nous

Ex : On joue. → Il joue / Nous jouons.

ont

C'est le verbe avoir au présent (ils/elles ont)

Astuce : On peut le remplacer par avaient

Ex : Ils ont des livres. → Ils avaient des livres.

🎭 Leçon 11 : Homophones ce/se et ces/ses

Distinguer ce/se et ces/ses CM

ce / se

ce

C'est un déterminant démonstratif (montre quelque chose)

Astuce : On peut le remplacer par un

Ex : Ce chat est mignon. → Un chat est mignon.

Aussi dans : c'est, ce sont

se

C'est un pronom réfléchi devant un verbe pronominal

Astuce : On peut le remplacer par me ou te

Ex : Il se lave. → Je me lave / Tu te laves.

ces / ses

ces

C'est un déterminant démonstratif pluriel

Astuce : On peut le remplacer par ce/cette au singulier

Ex : Ces livres. → Ce livre / Cette table.

ses

C'est un déterminant possessif pluriel (à lui/elle)

Astuce : On peut le remplacer par son/sa au singulier

Ex : Il range ses livres. → Il range son livre / sa table.

🎯 Exercice : ce/se et ces/ses

1. "___ chat est mignon"

2. "Il ___ lave"

🌈 Leçon 12 : Homophones lexicaux

Les homophones lexicaux CM

Des mots qui se prononcent pareil mais ont des sens différents.

Les principaux homophones lexicaux

ver / verre / vers / vert

  • ver : l'animal → un ver de terre
  • verre : on boit dedans → un verre d'eau
  • vers : direction → aller vers Paris
  • vert : la couleur → un pull vert

mer / mère / maire

  • mer : l'océan → la mer est bleue
  • mère : maman → ma mère
  • maire : chef de la ville → le maire de Paris

cou / coup / coût

  • cou : partie du corps → le cou de la girafe
  • coup : action de frapper → donner un coup
  • coût : le prix → le coût d'un livre

pain / pin

  • pain : on le mange → une baguette de pain
  • pin : l'arbre → une forêt de pins

saut / seau / sot

  • saut : action de sauter → faire un saut
  • seau : récipient → un seau d'eau
  • sot : bête, idiot → être sot

✂️ Leçon 13 : L'apostrophe

L'élision CP-CE

L'apostrophe remplace une voyelle qui disparaît devant un mot commençant par une voyelle ou un h muet.

Quand utilise-t-on l'apostrophe ?

1. Les articles le, la

le et la → l'

Ex : le arbre ✗ → l'arbre ✓

Ex : la école ✗ → l'école ✓

2. Les pronoms je, me, te, se

Ex : je arrive ✗ → j'arrive ✓

Ex : tu me aimes ✗ → tu m'aimes ✓

Ex : il se appelle ✗ → il s'appelle ✓

3. Les mots que, ne, de, si

Ex : que est-ce ? ✗ → qu'est-ce ? ✓

Ex : si il vient ✗ → s'il vient ✓

Ex : ne oublie pas ✗ → n'oublie pas ✓

Ex : le livre de Emma ✗ → le livre d'Emma ✓

4. Mots composés

Ex : aujourd'hui, quelqu'un, presqu'île, lorsqu'il

⚠️ Pas d'apostrophe devant

  • h aspiré : le héros, la hache (pas d'élision)
  • certains mots : le onze, le un, le oui

➖ Leçon 14 : Le trait d'union

À quoi sert le trait d'union ? CM

Le trait d'union relie plusieurs mots pour en former un seul.

Quand met-on un trait d'union ?

1. Les nombres composés

On met un trait d'union entre tous les éléments d'un nombre composé

Ex : vingt-trois, quatre-vingt-dix-sept, trois-cents

⚠️ Sauf : vingt et un, cent deux (pas de trait d'union avec "et" ou devant "cent", "mille")

2. Les mots composés

Ex : un arc-en-ciel, un rouge-gorge, un tire-bouchon, un gratte-ciel

3. L'inversion du sujet

Dans les questions avec inversion :

Ex : Viens-tu ? Est-il là ? Parle-t-elle ?

⚠️ Le t euphonique : Va-t-il ? Mange-t-on ?

4. Avec les pronoms personnels

À l'impératif avec un pronom :

Ex : Donne-moi, prends-le, va-t'en

5. Certains préfixes

Ex : ex-président, anti-virus, sous-marin

6. Mots particuliers

  • c'est-à-dire
  • peut-être
  • quelqu'un, quelque chose (pas de trait d'union)
  • là-bas, là-haut, celui-ci, celle-là
